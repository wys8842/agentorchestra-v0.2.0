## 设计原则

### 1. 领域驱动

代码按业务领域组织，而非技术层次。

### 2. 渐进增强

特性默认关闭，按需启用。

### 3. 可插拔

存储/追踪/指标均可替换。

### 4. 向后兼容

经典 API 路径保留。

## 核心概念

### Agent

智能体：思考+决策+工具调用

### LoopState

循环状态：Plan/Evidence/Budget/Reflection

### Checkpoint

检查点：状态快照

### WAL

预写日志：操作记录

### Fencing Token

栅栏令牌：防僵尸事务

### Namespace

命名空间：租户隔离
